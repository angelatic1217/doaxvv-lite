# doaxvv-lite

DOAXVV 個人資料系統的**線上精簡版網頁外殼**：在手機、平板或其他電腦上填報抽卡紀錄、查看資源與卡池，不需要開著遊戲電腦。

這個儲存庫只有網頁程式，**不含任何資料**。資料放在另一個私人儲存庫，網頁以使用者自己貼上的 GitHub 權杖讀寫。

## 功能

| 分頁 | 內容 | 可否修改 |
| :--- | :--- | :--- |
| 紀錄 | 現有資源、記錄中的抽卡紀錄、最近紀錄；開新紀錄、追加出貨／結束、填資源快照 | 可（只新增） |
| 未來視 | 各期預計日期、願望件數與期望抽數、預算累計；可改每期投入上限並即時重算 | 只能改投入上限 |
| 時間軸 | Steam／日服的轉蛋與活動公告，可依種類、無償／有償、標籤、角色、文字篩選 | 唯讀 |
| 圖鑑 | 泳裝卡片與詳情，持有／覺醒／願望狀態 | 唯讀 |
| 設定 | GitHub 帳號、資料儲存庫、分支、權杖、「不顯示圖片」 | — |

版面依視窗寬度自動切換：窄於 760px 為手機底部分頁，760～1099px 為平板頂端分頁，1100px 以上為電腦左側欄。

## 運作方式

```
本機系統（doaxvv.db 正本、爬蟲）
   │  線上同步：匯入 inbox/ → 匯出 snapshot/ → git push
   ▼
私人資料儲存庫  ◀── 本網頁透過 GitHub 內容 API 讀 snapshot/、寫 inbox/
```

* 網頁先讀 `snapshot/manifest.json`，只下載雜湊值變了的檔案，並存在瀏覽器的 Cache Storage。
* 每次填報寫一個新的 JSON 檔到 `inbox/`，不覆寫既有檔案；本機下次同步時匯入並刪除。
* 一定要連線才能儲存；寫入失敗時輸入保留在畫面上，不在裝置上排隊。
* 只能撤銷尚未匯入的最後一步；已匯入的資料要回本機修改。
* 快照與網頁的主版本不同時，網頁停止顯示資料並提示更新。

## 第一次使用

1. 建立 fine-grained personal access token：
   * Repository access：只選私人資料儲存庫
   * Permissions → Contents：**Read and write**
   * 期限：366 天
2. 開啟本站 →「設定」→ 填 GitHub 帳號、資料儲存庫名稱（預設 `doaxvv-lite-data`）、分支、權杖。
3. 手機可用瀏覽器的「加到主畫面」安裝成 App（PWA，網站外殼由 service worker 快取）。

權杖只存在該裝置的瀏覽器。權杖失效時網頁會提示重新貼上；裝置遺失時到 GitHub 撤銷該權杖即可。

## 圖片

本站不存放遊戲圖檔，泳裝卡面與角色頭像以連結載入：先讀 `doaxcc/doaxvv_bromide`，失敗改用 doax.cc，再失敗顯示佔位圖；只載入捲動到畫面內的圖片。「設定」可開「不顯示圖片」作為省流量模式。

## 安全

* Content-Security-Policy 只允許本站腳本與樣式、只連線 `api.github.com`、圖片只來自上述來源與官方網站；`no-referrer`。
* 頁面設 `noindex`，不供搜尋引擎收錄。

## 開發與發佈

**請不要直接修改這個儲存庫。** 原始碼在開發用（不公開）儲存庫的 `lite_site/`，由本機系統「資料同步與圖片管理」→「線上精簡版」→「發佈網頁」（或 `python -X utf8 -m backend.modules.lite.sync --publish`）整個複製過來後推送。發佈時會刪除這裡除了 `.git`、`.nojekyll`、`README.md`、`LICENSE` 等少數檔案以外的所有檔案。

* 原生 JavaScript（ES 模組）與純 CSS，無建置步驟。
* GitHub Pages：`main` 分支、根目錄；`.nojekyll` 關閉 Jekyll 處理。
